# Per-game marketing copy

Playbox ships as one Play listing, so these are not store listings any more.
They are still the sharpest description of each game — use them for screenshot
captions, the what's-new sheet, a press note, or as the starting point if you
ever split a game out into its own app.

The full original per-game listings (short + full descriptions, ASO keywords,
content-rating answers) are in this repo's git history at the commit before the
single-app rework, and the per-game store artwork is still generated into
`store-assets/<slug>/`.

| Game | One line | Long form |
|---|---|---|
| Echo | The maze is dark. Ping to see it — then remember. | A puzzle game played almost entirely in the dark. A ping lights every wall it touches for about three seconds, then the dark takes it back. Pings are limited. Drifters are invisible and a ping paints them red for an instant. Sirens cannot be seen at all — you find them by a tone that rises as you close in. Sixty fixed levels. |
| Starfall | Fling a comet through real gravity. Never steer. | An endless orbital climb. You launch, and inverse-square gravity from every planet bends the flight, so the line you plan is never the line you fly. Skim a planet at speed for an assist worth bonus distance. Stardust to collect, pulsars that shove, black holes with no second chance, and a void rising from below. |
| Prism | Split white light into colour, then put it back together. | A light-routing puzzle where colour is a resource. Prisms split white into red, green and blue; filters subtract; combiners add back. Forty-five hand-built levels, each machine-verified solvable, each par proven minimal by exhaustive search. Stray light you forgot about is what keeps you stuck. |
| Vortex | Rings collapse inward. Find the gap. | Radial dodging with one input. Hold a side to orbit, drag to steer directly, double-tap to dash fifty degrees. Eight zones add rotation, twin gaps, shutters that close, reversed spin, phantom rings, then offset pairs. Every ring is proven reachable before it spawns — hard, never cheap. |
| Daily Lock | One lock a day. Six tries. No words in it. | Five dials, seven glyphs. Solid ring means right glyph right dial; hollow means right glyph wrong dial; dim means absent. Marks are shapes, not colours. Every lock states one structural rule up front — mirrored, ascending, one repeats twice — and that rule is what turns six tries from luck into deduction. |
